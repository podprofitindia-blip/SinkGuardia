# NESTORA Website — Starter Package

A responsive premium static website based on the approved NESTORA homepage concept.

## Files
- index.html — page structure and content
- styles.css — premium responsive styling
- script.js — product cards, cart drawer, menu and newsletter interactions

## Important before launch
1. Replace demo products/prices with real affiliate products.
2. Replace each "Add to Cart" action with your affiliate "Check Price" / merchant link.
3. Add real product images.
4. Add Privacy Policy, Terms, Disclaimer and Affiliate Disclosure pages.
5. Verify NESTORA domain/trademark/social handles before public launch.
6. Connect analytics and Search Console.
7. Add a proper contact email and business details.

This package is a front-end starter; it does not process real payments or orders.
